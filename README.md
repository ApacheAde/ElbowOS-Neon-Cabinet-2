# ElbowOS Neon Cabinet 2

Full-colour **Python 3** mini-games built with Pygame. Each title is an original, self-contained game — not a ROM emulator and not a Nintendo/Sega clone with copyrighted assets.

Featured link: **[https://x.com/ElbowOS](https://x.com/ElbowOS)**

## Games

| Game | Style | How to play |
| --- | --- | --- |
| **Pipe Hero** | Mario-style platformer | Arrows / AD move, Space jump, stomp walkers, grab coins, reach the flag |
| **Star Raiders** | Space-invader shooter | A/D move, Space fire |
| **Maze Muncher** | Pac-style maze | Arrows chomp pellets, power dots let you eat ghosts |
| **Neon 2048** | Puzzle | Arrows / WASD merge tiles to 2048 |
| **Neon Craps** | Casino dice | Space rolls, Up/Down changes the pass-line bet |
| **Colour Klondike** | Card solitaire | Click stock, drag red/black stacks, aces to foundations |
| **Connect Glow** | Table game | Click a column — four in a row wins |
| **Sky Racer** | Highway dodge | A/D steer, grab gold, avoid traffic |

There is no NES/SNES *Mario Bros* emulator here. A real emulator needs copyrighted ROMs and a CPU/PPU core; this pack ships original gameplay inspired by arcade genres instead.

## Run

```bash
python3 -m pip install -r requirements.txt
python3 launcher.py
```

Or start one title directly:

```bash
python3 pipe_hero.py
python3 star_raiders.py
python3 maze_muncher.py
python3 neon_2048.py
python3 neon_craps.py
python3 klondike.py
python3 connect_glow.py
python3 sky_racer.py
```

Needs Python 3.10+ and a display (Pygame window).
